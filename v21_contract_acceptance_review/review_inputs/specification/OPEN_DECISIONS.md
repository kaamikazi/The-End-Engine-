# Remaining implementation/review gates, not unresolved normative choices

Material design choices R1/R3 are selected in this proposal: common coordinated cut or downgrade; no hash-equality atomicity inference; exact mandatory witness coverage; bounded retry/no in-epoch retry after violation; three disjoint serialized members and one external typed-error channel; exact null/absent/empty meanings; source artifact persistence distinct from envelope persistence; existing provenance gate always independent. There is no opt-out allowing timestamps alone to earn a strong tier.

Independent v2.1 acceptance remains PENDING. Actual APIs/observer/adapter are NOT implemented; this task authorizes none. Later implementation must prove writer-domain coverage and native guard/pin/resource ordering without changing F01 semantics, implement read-only pinned-buffer parsing and trusted proof checks, complete the R4 caller inventory and execute full R4/R5 tests. If current writers cannot provide that domain/consistency, the specified downgrade is mandatory; no stronger guarantee is assumed. Unsupported platforms get lower authority, not invented atomic snapshots.

External consumer reach, provider compatibility, authenticated external human approval, semantic adjudication, contamination clearance and empirical experiments remain UNKNOWN/PENDING/NOT_RUN. These are explicit limits and separate future scopes, not hidden claims of compatibility or model performance. A prospective schema/model fixture pass is not implementation acceptance. Git archival publication, if safe, records design only and does not approve it.
