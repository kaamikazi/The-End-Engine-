# Remaining coverage gaps

This patch covers explicitly enrolled **Ledger** initialization and L3 read/mutation transactions only. It does not implement all-writer enrollment, A/S snapshot classes, a production R1 observer, native witnesses, R3 adapter, complete run accounting or scientific experiment readiness.

Uncovered: default/old/unconfigured Ledger clients (the negative control proves their pending write), arbitrary external/administrative actors, untracked old-code L3 holders, run-root admission/constructor directories, gateway closure read/merge/pending/replace, journal append and raw response anchors outside the ledger, publication/global-binding/event/recovery-hold writers, late/finally logging, and Engine/baseline trajectory/replay paths beyond the verified existing L1 assumptions. No neighboring module was edited to close them. The control identity is not a coverage token or evidence origin authentication.

Full stronger authority still needs approved producer/resource/participant coverage, other shared storage/creation boundaries, complete recursive same-cut names/types/bytes/absences and immutable buffers, mandatory original native/architecture witnesses and raw usage/closure coverage, unchanged same-cut source-core proof, strict accepted-schema/external-semantic validation and independent concurrency/crash/reader acceptance. All IP01–IP09 requirements remain where applicable. A passing ledger guard alone does not discharge any whole-runtime acceptance gate.

Only the enrolled guarantee is asserted. Tested native aliases include actual hard links and case variants; no distinct8.3 alias or privileged junction was forced. Process termination, standard threads, logical reentry and supported native errors were exercised. Arbitrary old module copies/subinterpreters/abandoned live threads/remote filesystems and hostile host actions remain outside the validated profile. No power-loss or universal correctness proof follows from fsync/replace.

Historical31 outcomes, A0 and the original N12 FAIL remain unchanged. The four initial new collector errors and one path-policy test failure are retained with exact sources; none was rescaled or silently replaced. New source changes stayed inside the approved module/symbols and new test namespace. No A1 or native witness implementation, provider call, benchmark, tag, merge or release is authorized by this handoff.
