# Three competing experimental designs — NOT IMPLEMENTED

These are competing causal interventions, not proven replacements. Keep current Engine source frozen. Any later prototype must be a separately authorized isolated experimental adapter with its own fingerprint and invariant tests. All use the same initial-generation mode, model/settings, answer-scope/evidence safeguards and external measurement contract. No benchmark-specific repair prompt or hidden scoring key enters runtime.


### Shared non-negotiable invariants

MODEL AGREEMENT IS NOT VERIFICATION. Task text is not automatic external truth; model plans are proposals, not user instructions. No revision manufactures evidence. Only actual configured candidate-bound checks can earn scoped support; confidence/agreement cannot promote unverified claims. Failed scoped deterministic checks remain consequential. Mandatory constraints cannot be bypassed by acceptance or early stopping. Lineage, best/latest IDs, rollback reasons and all physical calls remain auditable and bounded. External side effects need authorization. Jev stays optional and supplies no evidence authority; all proposed first experiments use baseline decisions. Checkers do not prove universal correctness. A guard may withhold unsafe output while external task quality fails; report both.

## A — Sparse deliberation with revision gating

| Dimension | Proposal |
| --- | --- |
| 1 Core hypothesis | Grounded actionable failure eligibility plus C0 preservation reduces harmful/redundant rewrites without losing valid corrections. |
| 2 Components retained | Candidate/answer scope, lineage, finite contract/status/reference checks, optional scoped checker, ledger/budget and auditable rollback/withholding. |
| 3 What changes | One bounded issue probe only when finite uncertainty/actionability warrants it; explicit eligibility record and retain-C0 default. One repair maximum; outcome measured against the targeted invariant. |
| 4 Removed/bypassed | Routine full primary/adversarial/test generation on every text-equivalent candidate; utility-driven multi-cycle churn and broad rewrite fallback when no actionable defect exists. |
| 5 Required information | Actual C0; task constraints versus assertions; candidate-bound failure or explicit unresolved requirement; required safety actions and absence of independent observations. |
| 6 Why might improve answers | Protects new BA-008 explanation and avoids already-satisfied temperature repairs; relevant bounded failures can still trigger one correction. |
| 7 Why might fail | Misses subtle unmeasured defects; imperfect eligibility may protect wrong C0 or overtrigger. Lack of world evidence may require uncertainty rather than a correctness verdict. |
| 8 Inference structure | C0=1; if eligible, probe/critique1 + revision1 + advisory recheck/comparison1; maximum4 physical calls including any replacements, not4 plus unlimited repair. Deterministic checks add0 model calls. |
| 9 Compatibility | Experimental condition ID, additive gate-decision and skipped-stage records; no reinterpretation of old trajectories. Preserve schema/Engine API via adapter; no claim of native internal policy equivalence. |
| 10 Safety/evidence invariants | Shared invariants; hard failed constraints cannot be accepted by sparse stop; unsupported status/reference additions corrected or withheld; retain reasons for every skipped stage. |
| 11 Minimal implementation slice (future only) | Read-only C0 observer + eligibility record + single repair path + unchanged-scope fallback. No production utility edits or new operators needed for the slice. |
| 12 Falsifiable prediction | On fresh passing-C0 cases: fewer meaningful regressions than frozen END with preserved quality/safety. On repairable failures: positive final-minus-C0 must occur; lower calls alone fails answer-improvement criterion. |
| 13 External measurements | C0/final correctness, missing constraints, issue precision/recall on bounded labels, eligibility decisions, regression/safety/withholding, meaningful delta and full cost. |
| 14 Stop criteria | One repair/no eligible issue/end-of-budget; unresolved mandatory safety ends with explicit failure/withholding. Halt study on authority invariant violation. |
| 15 Cost risks | Eligibility probe can be as expensive as critique; false eligibility wastes capped calls; too little scrutiny can conceal real safety cost. |

## B — Evidence/constraint-directed repair

| Dimension | Proposal |
| --- | --- |
| 1 Core hypothesis | A bounded failure→specific delta→preservation/check contract outperforms generic plans on repairable cases, even with the same issue and model. |
| 2 Components retained | Task/answer provenance, candidate lineage, scoped trusted checker interface, evidence contracts/reference registry, guards, rollback and ledger/accounting. |
| 3 What changes | Maintain one repair objective: failed constraint/claim, allowed data, proposed measurable delta, unaffected invariants, and explicit evidence-acquisition availability. Unsupported causal gap maps to request/qualify, not fabricated metrics. |
| 4 Removed/bypassed | Broad open-weakness shopping, severity-driven correction, unbounded model-plan instruction authority and generic rewrite after unusable plan. |
| 5 Required information | Grounded finite issue, actual parent text, checker scope or literal task constraint, permitted evidence IDs, known unavailable information and preservation requirements. Hidden external evaluator forbidden. |
| 6 Why might improve answers | Targets old numeric/type/format defects rather than ordering noise; prevents BA-009 unavailable-metric insertion and protects explanation/key contracts. |
| 7 Why might fail | Cannot repair unknown root cause without observations; constraints may be uncheckable; model can ignore valid delta. Overconservative grounding may suppress a real defect. |
| 8 Inference structure | C0=1 + bounded issue probe1 + objective/plan1 + revision1 + advisory comparison1; maximum5 physical calls. Trusted local finite checks are0 inference; paid/external acquisition excluded. |
| 9 Compatibility | Additive RepairObjective research record and links to original issues/constraints; existing CheckContract lifecycle retained. Keep source/prompt changes isolated in future adapter and hash it separately. |
| 10 Safety/evidence invariants | Shared invariants; unavailable data explicitly remains unavailable; new cited IDs must belong to registry, model-origin plan cannot expand task/evidence authority; scoped failed check prevents acceptance. |
| 11 Minimal implementation slice (future only) | One closed repair objective with deterministic preservation checklist, no new general planner framework. Generate one complete child, audit its objective delta and reference/status change. |
| 12 Falsifiable prediction | Among independently adjudicated valid objectives, more positive C0→final deltas and fewer unrelated contract losses than frozen END/A; if generation still fails valid plans, H4 gains support over H3. |
| 13 External measurements | Issue validity, plan executability, target repaired, preservation loss, unknown-reference/overclaim changes, quality/safety delta, objective count, calls/tokens/time and failures. |
| 14 Stop criteria | No supported executable objective: retain C0/qualify or withhold; one child maximum. Failed/check-unknown objective remains disclosed. Stop on any unsupported support promotion. |
| 15 Cost risks | Objective/contract setup adds tokens; trusted checks can be costly outside inference; preserving too much may freeze wrong structure; world-data acquisition would require a new authorized budget. |

## C — Bounded independent alternatives and grounded comparison

| Dimension | Proposal |
| --- | --- |
| 1 Core hypothesis | Different complete approaches escape a local rewrite loop; bounded diversity plus scoped selection provides better candidates than repeated plan-conditioned edits. |
| 2 Components retained | C0 retention, branch IDs/lineage and branch budget, authoritative answer scope, registered evidence/checker contracts, guarded comparison/selection, rollback and ledger. |
| 3 What changes | When the same grounded failure justifies exploration, generate exactly two complete independent alternatives directly from original task plus allowed data, without inheriting prior critique/plan text. Compare all candidates on retained constraints. |
| 4 Removed/bypassed | Multi-step causal-story synthesis and recursive branch depth; repeated same-parent rewrites; automatic adoption merely because a model branch is PROMISING. |
| 5 Required information | Original task/allowed evidence, a bounded trigger, C0 and two full solutions; measurable scoped checks and uncertainty. Diversity text is not independent world evidence. |
| 6 Why might improve answers | May escape wrong74.7 or local explanatory collapse; C0 remains available and hidden evaluation measures candidate-set potential separately from selected final. |
| 7 Why might fail | Same model may generate correlated wrong candidates; advisory comparator can still miss the best. Alternative causal stories are not observations, and merging can manufacture authority. |
| 8 Inference structure | C0=1 + two alternative generations2 + one advisory comparison1; ordinary4, hard maximum5 including one permitted repair within cap. No recursive branches/synthesis/revision loop. |
| 9 Compatibility | Condition ID with parent=C0 plus sibling alternative IDs; preserve original histories, mark independent prompt provenance. New adapter can reuse bounded branch/compare records but must not relabel hypotheses as evidence. |
| 10 Safety/evidence invariants | Shared invariants; checks apply to each actual candidate, not transferred receipts. Mandatory format/safety filters precede preference; unknown branches retained as unknown, no discarded-branch importing. |
| 11 Minimal implementation slice (future only) | Two independently prompted complete candidates, one comparison over admissible set, C0 fallback. No new general tree-search engine or optimizer. |
| 12 Falsifiable prediction | More distinct admissible candidates and higher externally scored candidate-set maximum than A/B; if potential rises but selected quality does not, H5 is implicated. Diversity without quality/safety gain falsifies claimed benefit. |
| 13 External measurements | Candidate-set maximum is a retrospective diagnostic only, distinctness/proposition overlap, chosen-candidate regret, final-minus-C0, regressions, safety and whole branch cost. |
| 14 Stop criteria | Exactly two alternatives then compare once or deterministic fallback; no tie retries. All unsafe candidates→explicit failure/withholding; hard budget exhaustion reported. |
| 15 Cost risks | Additional full generations are historically the slowest call type; comparison can be bottleneck or target for verbosity bias; two alternatives do not establish broad search superiority. |

## Distinguishing the interventions

A tests whether a scarce repair trigger plus preservation suffices. B tests executable repair prescriptions after fixing issue eligibility. C tests candidate diversity and selector regret. Common provenance/check guards are retained across all three, rather than giving one condition privileged hidden evaluator access. These interventions change different call structures, so report both capped native costs and outcome deltas; do not call any successful solely for efficiency. Stronger-model routing and evidence acquisition are later separate factors, not silently bundled into a winning architecture. No design may promise to infer absent causal data by additional opinions.
