Provider-backed token claims additionally require validated actual backend receipt semantics. No current run is awarded this status, and all certified totals are null.

An observed fixture sum is not a run total or lower-bound efficiency estimate. The current observations have this status for the real completeness endpoint.
- UNKNOWN_ACCOUNTING has no supportable relevant observation or original association; use nulls and explicit missing causes, not zeros or an empty-history assertion. Reserved-but-undispatched/unknown outcomes stay separate.
- INVALID_COMPARISON applies whenever a required run total or endpoint is missing, conflicting, unproved or differently scoped. Block full-cost rankings and quality-per-cost ratios; preserve partial observations without imputing, interpolating, normalizing by budgets, assigning zero to failed cells, dropping them, or inferring usage from answers.
