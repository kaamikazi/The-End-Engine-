## Scientific justification and decision to resolve

The full mission includes comparable resource costs for all six conditions. I/X cannot establish the full historical set or complete totals and cannot issue any v2.1 NORMAL/RESTRICTED view. A new A/S cut is required for those eligible views, and A plus independently VERIFIED source/raw/usage/settlement/closure coverage is required for COMPLETE totals. Thus shipping an I/X-only observer as sufficient would fail a stated scientific endpoint.

It also does not follow that protected production writer changes are the uniquely minimal remedy. The approved contract permits an independently justified complete cooperative operational domain. The existing A0-17 two-participant model does not prove one, and A0-18 demonstrates an actual permitted direct-register bypass. In addition, native baseline and architecture paths have different evidence durability and elapsed-time scopes, all transports are canned/offline, and recorded reservations are not authenticated actual provider inference or bills. Strong capture alone does not close these gaps.

Resolve one explicit disjunction in one offline slice: **Can a precisely declared single-host, post-generation operational profile with unchanged production APIs (a) exhaustively exclude/drain every actual supported writer and inner-lock user, and (b) bind the original six-condition source/closure/usage evidence into an evidence package satisfying the specified endpoints?** If yes, independently document that bounded profile as a feasible prerequisite for a later capture implementation. If no, return the exact failed producer/evidence edge and the smallest separately reviewable enrollment/recording source boundary; do not expand into production code. An UNKNOWN is an explicit failed readiness gate, not permission for indefinite probes.

## Why this is minimal

The decisive unknown is the exact evidence-producing and exclusion boundary needed for the stated endpoints. A diagnostic-only implementation leaves the complete-cost endpoint knowingly unsatisfied. Immediate broad writer modification commits to an invasive remedy before resolving whether a complete operational profile suffices and whether native evidence needs separate recording work. This one finite, offline slice resolves that disjunction while preserving every accepted safety boundary. It does not seek maximum authority for diagnostic fields, relax certification, fabricate actual candidates, estimate missing costs or recommend live inference.
