All claims name exact source group, run/attempt IDs, raw-byte references, origin limitations and capture time/scope. Unknown-origin data stays UNVERIFIED; X means no supportable attempt association, empty observations and an explicit reason, never zero historical attempts. X cannot simultaneously assert a grounded candidate/attempt fact. Missing registered source versus unreadable source versus explicit recorded NO_RESPONSE must differ.
